## 它是什么

一个 Windows 桌面上的酷安客户端：**一个 exe 文件，双击就能用**，不需要安装、不需要解压，也不需要额外的运行时（除系统自带的 WebView2）。

界面是**三栏结构**——左侧导航 / 中间信息流 / 右侧栏——并按 `prototype/home.html` 的设计稿重排了首页：

- 顶栏**左上角是酷安 logo 与名称**，**右上角**依次是通知、私信、主题切换、账号入口（头像，悬停弹出资料浮层）与窗口按钮
- 首页顶部有「首页」大标题 + 副标题 + 热词胶囊，下面是一整块**换行的胶囊栏目行**（推荐 / 关注 / 头条 / 热榜 / 快讯 …）
- 信息流是**白底圆角卡片**；切到「双列」后是**两个各自独立滚动的瀑布流**，滚一列不影响另一列
- 左右栏用**分界线上的悬停手柄**收起 / 隐藏：手柄平时隐形，鼠标移近才浮现，点一下即收放；栏隐藏后手柄常显，随时能点回来
- 发布入口是内容区底部的**悬浮毛玻璃按钮**，按住可以拖到任意位置，松手后记住位置（下次启动还在那儿）

全站的配色、圆角、描边、标题层级、选中态**收敛在同一套令牌与统一皮肤里**，不是每个页面各写一份。

## 下载

到 [Releases](https://github.com/SymonChu/coolapk-windows/releases/latest) 下载 `coolapk-windows.exe`：
**免安装、免解压**，双击即运行。

- 依赖系统自带的 **WebView2**（Windows 10/11 一般已内置）
- 目前**未做代码签名**，首次运行可能被 SmartScreen 提示「未知发布者」——选择「更多信息 → 仍要运行」即可
- 应用数据（登录态、设置）在 `%APPDATA%\com.coolapk.windows`，删掉该目录相当于恢复出厂

## 界面

![设置页](docs/preview/app-settings.png)

*以上两张截图都是**客户端前端的实际渲染**（本地快照，未登录状态 + 假数据），不是设计稿。首页那张是**双列**形态——也就是两个各自独立滚动的瀑布流；单列 / 双列可在信息流右上角切换，独立话题页顶栏也有同一个开关。*

| | |
|---|---|
| **顶栏** | 左：酷安 logo + 「酷安」；中：前进 / 后退 / 刷新 / 回到顶部 + 搜索框（Ctrl+K）；右：通知、私信、主题切换、账号入口（头像，悬停出资料浮层）、窗口按钮；整条栏高 **40px**（紧凑到只留必要留白） |
| **左侧导航** | **三大模块**，每块一张圆角卡：**频道**（首页 / 数码 / 发现 / 话题 / 酷图 / 更多）、**我的社区**（通知 / 消息 / 历史 / 收藏 / 关注 / 我的）、**个人中心**（头像 / 昵称 / 等级 / 经验条 / 签名 / 获赞·关注·粉丝 + 常显「个人主页 / 我的收藏 / 浏览历史 / 应用设置」）——**设置入口只在这里**，导航里没有独立的「设置」行；栏可收起为图标栏（收起时卡片退化为无卡列表） |
| **中间** | 首页大标题 + 热词胶囊 + 胶囊栏目行；信息流单列 / 双列可切，双列时两列各自独立滚动；**独立话题页也有单列 / 双列开关**（与首页共用同一份设置） |
| **右侧栏** | 我关注的话题（登录后**置顶**）、欢迎来到酷安（未登录时）、本月热榜、热门话题；可整块隐藏。热门搜索词不在这里，点开顶栏搜索框即可看到 |
| **发布入口** | 内容区底部居中的悬浮毛玻璃钮（「+ 发布动态」），按住可拖动，位置会记住 |

左右栏怎么收放：把鼠标移到**左栏右缘 / 右栏左缘的分界线**上，会浮现一个竖条小胶囊手柄，点它收起或还原。右栏只在首页存在，窗口宽度小于 1200px 时右栏本身不显示。

`prototype/home.html` 是首页的**可交互设计稿**（稿子里的左右栏开关是稿子自带的控件，与客户端的悬停手柄不是同一套）：用浏览器打开后可以自己试左右栏显隐，也支持 `?state=hide-left,hide-right` 预设状态；设计稿的静态渲染图在 `docs/preview/home.png`。

## 构建

环境：Node.js ≥ 22、Rust stable、[Tauri 2 系统依赖](https://v2.tauri.app/start/prerequisites/)、WebView2 Runtime。

```bash
npm install
npm run typecheck          # 类型检查
npm test                   # 单元测试
npm run tauri build -- --no-bundle    # 只出单文件 exe，不打包安装器
```

产物：`src-tauri/target/release/coolapk-windows.exe`。

推送 `v*` 形式的 tag 会触发 GitHub Actions：构建 → 在构建机上真跑一次 exe（启动自检）→ 通过后把单文件挂到 Release。

## 排障

**登录态 / 设置存在哪？** `%APPDATA%\com.coolapk.windows`。

**换了版本要重新登录？** 应用数据目录跟随应用标识走；标识一旦变更就是一份全新目录，旧登录态不会自动继承。

**悬浮发布按钮拖歪了想复位？** 它的位置存在设置里的 `publishFabPosition`；把设置里的这一项清掉（或删掉设置文件）就会回到默认的底部居中。
